# Blog Preview Card

A responsive Blog Preview Card built using HTML and CSS.

## Overview

This project is a simple blog preview card that displays information about a blog article in a clean and responsive layout.

The card includes:

* Blog cover image
* Category label
* Publication date
* Blog title
* Short description
* Author information


## Built With

* HTML5
* CSS3
* Flexbox
* Responsive Design

## What I Learned

While building this project, I practiced:

* Structuring components using semantic HTML
* Creating responsive layouts with CSS
* Using Flexbox for alignment
* Working with typography and spacing
* Creating hover states
* Organizing project files
