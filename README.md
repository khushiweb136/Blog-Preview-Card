# Blog Preview Card

A responsive Blog Preview Card built using HTML and CSS.

## Overview

This project is a simple blog preview card that displays information about a blog article in a clean and responsive layout.

The card includes:

* Blog cover image
* Category label
* Publication date
* Blog title
* Short description
* Author information

## Getting Started

### Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/blog-preview-card.git
```

2. Navigate to the project directory:

```bash
cd blog-preview-card
```

3. Open `index.html` in your browser.
